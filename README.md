# AI Tweet Sentiment Analysis 🚀

An AI-powered NLP project that analyzes tweets and predicts their sentiment as **Positive**, **Negative**, or **Neutral** using Machine Learning and Natural Language Processing techniques.

---

## 📌 Project Overview

This project was developed during my internship at **CODEC TECHNOLOGIES**.  
The model preprocesses tweet text, converts it into numerical vectors, and predicts sentiment using a trained Machine Learning model.

---

## ✨ Features

- Tweet Sentiment Prediction
- NLP-based Text Preprocessing
- Real-time Custom Tweet Testing
- Positive / Negative / Neutral Classification
- Machine Learning Model Integration
- Google Colab Compatible

---

## 🛠️ Tech Stack

- Python
- Google Colab
- Scikit-learn
- Pandas
- NumPy
- NLP

---

## 📂 Workflow

1. Data Collection
2. Text Cleaning & Preprocessing
3. Stemming & Tokenization
4. Feature Extraction using Vectorization
5. Model Training
6. Sentiment Prediction
7. Testing on Custom Tweets

---

## 📊 Example Output

| Tweet | Prediction |
|------|------|
| "I love this AI project!" | Positive |
| "Worst experience ever 😭" | Negative |

## 🚀 How to Run

1. Open the project in Google Colab
